# Search Demand Dashboard

Интерактивная матрица возможностей Яндекса и Google по анализу поискового спроса.

**Актуальность данных:** 01.09.2026

## Онлайн-дашборд

После включения GitHub Pages страница доступна по адресу:

https://sancholit.github.io/search-demand-dashboard/

## Публикация GitHub Pages

Откройте **Settings → Pages** и выберите:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/ (root)`

Основной файл сайта: `index.html`.
