Методология

Служебный раздел: откуда берутся показатели и какие ограничения у источников.
Почему источники нельзя просто складывать
Wordstat может давать абсолютный count по своей методологии, Keyword Planner — приблизительный monthly volume, Google Trends — индекс 0–100. Дашборд поэтому анализирует один выбранный dataset/metric family за раз.
Какие данные должны поступать
Минимальный набор: dataset_id, date, query, value. Для расширенной аналитики: category, region, device, source_scope, precision. Статическая страница читает JSON из data/search-demand.json.
Официальные источники
Wordstat API ↗Keyword Planner API ↗Google Trends API ↗Search Console ↗
Дашборд не показывает вымышленные данные. Если источник пуст, интерфейс явно сообщает об отсутствии фактических наблюдений.
